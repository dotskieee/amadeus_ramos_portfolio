# Documents

## Resume

1. Export your resume as a PDF and save it here with this exact name: `resume.pdf`
2. Open `assets/js/script.js` and change `hasResume: false` to `hasResume: true`
3. Commit and push the change (see the main README, "Update the site later").

Until you do this, the **Download Resume** button in the page header scrolls to the Resume section, and the button in that section is shown as unavailable with a note, so visitors never hit a broken link.

Tips: keep the file under 1 MB, and avoid putting your home address or phone number in a public PDF unless you want them to be public.
