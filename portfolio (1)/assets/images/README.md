# Images

Put your images in this folder. Every file below is optional; the site works without any of them.

| File | Used for | Recommended size |
|------|----------|------------------|
| `profile.jpg` | Hero portrait (see the comment in `index.html`) | 640 x 800 px, under 150 KB |
| `project-name.jpg` | Project thumbnails (see the project card template in `index.html`) | 1280 x 800 px (16:10), under 200 KB |
| `og-image.jpg` | Link preview on social media (optional) | 1200 x 630 px, under 300 KB |
| `favicon.svg` or `favicon.png` | Browser tab icon (optional; a built-in one is used by default) | 64 x 64 px |

## Image optimization tips (Windows)

1. Resize first: open the image in **Photos** (Edit > Resize) or **Paint** (Resize), and enter the width above.
2. Save as JPEG: in Photos choose **Save as copy**; in Paint choose **File > Save as > JPEG picture**. Check the file size in File Explorer (right-click > Properties) and make it smaller if it is over the limit.
3. Use lowercase file names with hyphens and no spaces, for example `inventory-app.jpg`.
4. Always write a short `alt` description in `index.html` so screen-reader users know what the image shows.
5. Only upload photos and screenshots you have the right to publish.
